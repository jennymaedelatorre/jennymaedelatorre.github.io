AI-Based CO Monitoring System

Optimizing Student Learning Outcomes using RAG and LLM.

Python FastAPI LLM (Gemini 2.0 flash) Bootstrap RAG PostgreSQL

CILO Tracker is an AI-assisted system designed to support Course Outcomes (COs) monitoring. It uses Retrieval-Augmented Generation (RAG) and large language model to generate different types of assessments—including multiple choice, true or false, and identification—based on uploaded learning materials. The LLM also maps these assessments to corresponding course outcomes to ensure alignment. The system then monitors student progress and performance, while evaluation and scoring remain instructor-managed to maintain accuracy and academic integrity.
